        How this runs

        Local

        The site is static HTML, CSS, and JavaScript in docs/. From the repo root:

        python3 -m http.server 4173 --directory docs

        Then open http://127.0.0.1:4173.

        GitHub Pages

        The same files are what Pages serves. Expected live URL:

        https://xgamer791.github.io/forge-nexxus/

        No secrets. No backend. The forge runs in the page.

        What it does not do

        It does not call a model, store a brief, or connect a workspace. It stamps a first-cut spec so you can start with a map instead of a blank page.

        Forge Nexxus — spec bench. Spelling is Nexxus, with two x’s.
